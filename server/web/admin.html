この画面について

プラットフォーム全体の設定です。「自分の設定」ではないため、ここでの変更はすべての利用者に効きます。自分のアカウントと API キーは設定・API キーにあります。

  • 保存すると、変更した欄だけがサーバーへ送られます。触っていない設定は変更されません。
  • 1 つでも不正な値があれば、どれも保存されません。中途半端に一部だけ適用された設定は作られません。
  • 変更は数秒のうちに server と bot の双方へ伝わります。「再起動が必要」の設定だけは例外です。
  • config.yaml が持つのは、待ち受けと公開 URL・DB の接続先・画像の保存先だけです。ここにある設定の真実は DB にあり、config.yaml の対応する値は初回起動時の初期値としてしか読まれません。

締め出されたときは

管理ロールの指定を誤ると、この画面を含む管理操作をあなた自身が行えなくなります。その状態はこの画面からは直せません。

  • Discord の Administrator 権限を持つロールの保有者と、guild のオーナーは、管理ロールの設定に関わらず管理者として扱われます。
  • どちらにも当てはまらない場合の復旧は、DB へ到達できる者が CLI から python -m server.cli set-setting admin.role_ids '["ロール ID"]' を実行する経路だけになります。
