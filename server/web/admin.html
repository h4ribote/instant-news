この画面について

プラットフォーム全体の設定と分類(カテゴリ・タグ・報道社)を管理します。「自分の設定」ではないため、ここでの変更はすべての利用者に効きます。自分のアカウントと API キーは設定・API キーにあります。

  • 設定は変更した欄だけをまとめて保存します。1 つでも不正な値があれば、どれも保存されません。
  • カテゴリ・タグ・報道社は 1 件ずつ作成・編集・削除します。操作はその場で確定します。
  • 記事は必ず 1 つのカテゴリに属するため、カテゴリが 1 つも無いと記事を作れません。
  • 設定の変更は数秒のうちに server と bot の双方へ伝わります。「再起動が必要」の設定だけは例外です。

締め出されたときは

管理ロールの指定を誤ると、この画面を含む管理操作をあなた自身が行えなくなります。その状態はこの画面からは直せません。

  • Discord の Administrator 権限を持つロールの保有者と、guild のオーナーは、管理ロールの設定に関わらず管理者として扱われます。
  • どちらにも当てはまらない場合の復旧は、DB へ到達できる者が CLI から python -m server.cli set-setting admin.role_ids '["ロール ID"]' を実行する経路だけになります。
