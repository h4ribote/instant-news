記事を書く

下書き
見出しの直下と、一覧・Discord の embed に出ます。
画像をドラッグ&ドロップ、または貼り付け アップロードすると WebP に変換され、カーソル位置に Markdown が挿入されます。本文の画像は記事と同じ閲覧範囲で守られます。
訂正として記録すると、記事の冒頭に「この記事は訂正されました」とメモが出て、訂正前との差分を誰でも開けます。単なる更新と訂正はここで区別されます。

公開設定

Discord のロールで所属している社から選べます。公開後は変更できません(署名は公開の時点で凍結されます)。
どちらでも投稿者の記録は残ります(改版履歴に編集者として記録され、監査で追えます)。
主分類は 1 つだけ。
タグは slug で指定します(空白区切り)。国もタグで表します。通知先を持つタグは追加のチャンネルへも流れます。

閲覧範囲

あなたが持っているロールから選べます。報道社もロールであるため、その社のロールを選べば社内限定の記事になります。
🔓
カバー画像は閲覧制限の対象外です。 Discord の embed に出すため、カバーは URL を知る誰もが見られます。機密の記事では、中身が分かる画像をカバーに選ばないでください。本文中の画像は閲覧範囲で保護されます。

カバー画像

カバー画像をアップロード WebP に変換されます。og:image にも使われます。

速報・広告

トップに速報帯で出し、通知時に設定されたロールをメンションします。立てられるロールは限られており、権限が無い場合は保存時にエラーになります。
記事面・一覧・Discord の embed のすべてに「広告」と広告主名が表示されます。この表示は消せません。

公開

時刻を入れて「公開」を押すと予約になります。時刻になるとサーバーが公開し、bot が通知します。空のまま「公開」を押すと即時に公開します。
