アカウント

instant-news はパスワードを保持しません。ユーザー管理は Discord アカウントに一元化されています。
所属は Discord のロールで決まります。この画面からは変更できません。サーバーの管理者にロールの付与を依頼してください。
ロール限定記事の閲覧可否はこのロールで判定されます。Discord 側でロールが変わると bot が直ちに反映します。

API キー

購読中のタグ

購読したタグの記事が公開されると、あなた個人宛てに Discord の DM が届きます。タグに設定されたチャンネルへの通知とは別の仕組みで、購読はあなただけに効きます。購読はタグページからも切り替えられます。

API キーとは

外部のプログラムから記事を投稿するためのキーです。相場の自動投稿のように、機械が定期的に記事を出す用途を想定しています。

キーで投稿した記事も、あなたが責任を負う記事として記録されます。

安全のために

  • キーはパスワードと同じ扱いで保管してください。
  • 用途ごとに分けて発行すると、片方だけ失効できます。
  • キーの投稿頻度には上限があります。
  • 心当たりのない使用があれば、すぐに失効してください。
